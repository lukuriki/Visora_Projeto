# Frontend

Aplicacao Next.js do template base.

## Comandos

```bash
npm install
npm run dev
npm run build
npm start
npm run lint
```

## Ambiente

Copie `.env.example` para `.env.local`:

```bash
cp .env.example .env.local
```

Variavel principal:

```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api
```

As instrucoes completas do projeto ficam no `README.md` da raiz.
